# 作品预览与出处

这些 WebP 是 Met 官方 Open Access 原图的不裁切缩小版本（400、800、1200px），原始地址和藏品出处见 `src/data/artworks.json`。所有入选记录在 2026-10-01 经官方 API 确认 `isPublicDomain:true`。Met 将其公开领域开放图像按 CC0 提供；详见 https://www.metmuseum.org/about-the-met/policies-and-documents/open-access 。

本站手工整理中文标题、图像描述与标签，不代表馆方翻译或认可。高清 JPEG 不保存于仓库。用 `python3 scripts/refresh-previews.py` 重新核对权限并生成预览（需要 ImageMagick 7）；原图只在临时目录中处理，完成后删除。
