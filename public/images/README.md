# 作品预览与出处

186 个 WebP 是 62 件已核实作品高清版本的不裁切缩小图（400、800、1200px）；高清文件不保存在仓库。原始地址、具体馆藏、许可与署名见 `src/data/artworks.json`，逐件来源台账见 `docs/collection-sources.json`，本轮选择与核实说明见 `docs/collection-expansion.md`。

15 件直接来自 Met 官方 Open Access / CC0；其余通过 Wikimedia Commons 的 Public domain / CC0 文件及合法博物馆摄影提供。不要把 Commons 公有领域标签机械理解成任何博物馆官网图片都开放下载。呐喊摄影为 Nasjonalmuseet / Børre Høstland，CC BY 4.0（https://creativecommons.org/licenses/by/4.0/）；这些预览已缩小、移除文件附属元数据，没有额外裁切或调色。

本站手工整理中文题名、图像描述、风格与标签，不代表馆方翻译或认可。用 `python3 scripts/refresh-previews.py` 检查来源并刷新预览（Python 3、ImageMagick 7）；该脚本支持 Met / Commons，权限或地址改变需人工复核。Wikimedia 请求使用可识别的项目 User-Agent，遇到限流等待后重试，不绕过来源限制。
