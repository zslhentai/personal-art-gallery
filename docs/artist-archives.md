## 画家名录与独立档案

- 名录保留原有网格与分隔线，换成 4:5 矩形肖像、中文名、原文名、生卒年、19–24 字墙签、实时馆藏数量；不加圆形头像、阴影或统一滤镜。
- `#/artist/<artistSlug>` 为独立档案路由，既可从名录进入，也可从作品作者入口进入。支持刷新、直接访问、浏览器返回、文档标题和画家导航状态。
- 档案依次呈现肖像、姓名、生卒、国籍／活动地区、流派、两段原创中文简介、折叠资料来源、本馆作品。67 位画家的简介均约 216–243 字，没有复制百科原文。
- 馆藏继续使用原 GalleryGrid 和相同策展顺序。旧的 `#/?artist=...` 筛选链接仍可使用。

沿用 `src/data/artists.json` 的 `artistSlug`、`lifespan`、`description`、`sourceUrl`，补充：

```json
{
  "artistSlug": "vincent-van-gogh",
  "nameZh": "文森特·梵高",
  "nameOriginal": "Vincent van Gogh",
  "birthYear": 1853,
  "deathYear": 1890,

```

`deathYear: null` 用于卒年未知或只有下限的情况；约数与不确定性在 `lifespan` 中明示。纠正西斯莱旧墙签的 1840 年，改为 **1839**；德·霍赫不继续使用常被混淆的 1684 年卒年；阿尔泰米西娅标注 1654 年后，而非声称确切卒年。

构建新增 `validateArtists`：检查每位馆藏作者都有独立记录、名称与作品一致、唯一 slug、生卒、简介长度、至少两个资料链接、肖像路径与权利，缺肖像必须明确说明。新增作品对应新画家时，构建会提示补档案；计数仍从作品自动计算，没有手写配额或 CMS。

## 肖像与资料审查

最终采用 **60 幅肖像**：58 个 Public Domain 文件、2 个 CC0 文件。全部来自 Wikimedia Commons 有版权元数据的文件页，包括博物馆及档案馆的开放图像、自画像、历史肖像和历史照片。纪念肖像明确说明是后人作品，不冒充本人自画像或生前照片。具体作者、日期、来源、权利和原文件见 [artist-sources.json](artist-sources.json)。

7 位保留“肖像待考”：

| 画家 | 暂不采用的原因 |
| --- | --- |
| Johannes Vermeer | 《鸨母》中裁切人物仅被推测为本人 |
| Pieter de Hooch | 常见自画像身份有争议 |
| Jacob van Ruisdael | 未确认本人肖像；百科主图是风景画 |
| Meindert Hobbema | 常见画像制作于十九世纪，缺少本人相貌依据 |
| Jan van Eyck | 《男子肖像》可能为自画像，但不能当作已确认身份 |
| Francisco de Zurbarán | 常用肖像仅被认为可能是本人 |
| Grant Wood | 1932 年自画像尚未核实美国公版依据，即使 Commons 标注 Public Domain，也不直接采用 |

没有使用 AI 脸、现代复原、来源不明照片或作品封面替代。波纳尔的匿名历史照片有原件损伤，来源说明中明示，未擅自修复或重建面孔。未为不确定肖像降低身份和版权标准。

生平主要参考 Wikipedia 与 Wikidata，并交叉查阅英国国家美术馆、Met 艺术史文章、Cleveland 作者生平、Art Institute 作者档案、挪威国家博物馆、Leopold Museum，以及 Getty ULAN。67 位均保留可追溯机构资料；并非每个来源都覆盖完整生平，身份／年代与创作背景按来源内容分别核对。来源失败或搜到同姓其他作者的结果不作为该艺术家证据。

## 图片与性能

- 专门生成 320×400、640×800 WebP，逐幅检查自然裁切，保留原色；高清扫描只在研究临时目录中，未入库。
- 320px 版本平均约 18KB、最大低于 48KB；640px 低于 200KB。总计 120 个文件约 5.8MB（5.5MiB）。列表 lazy / async；手机详情肖像宽 104px，以 320px 版本覆盖 3 倍屏，桌面按需选择 640px。
- 固定 width / height 与 4:5 容器，加载失败保留同尺寸、带可访问名称的占位。失败时显示“暂未加载”，资料身份未确认时显示“肖像待考”，两者区分。
- 首页没有肖像请求，也没有新增高清原图预加载。浏览器延迟加载可能提前获取临近屏幕的缩略图，保持现有行为。
- 本地 Chromium / WebKit 的 375 / 390 / 430 / 1280px 检查未发现横向溢出，测得 CLS 为 0。WebKit CLS API 在不同真实设备上支持程度不同，不能替代真机测量。
- 完整档案文本使入口 JS gzip 从约 130.38KB 增至约 163.1KB，CSS 从 6.03KB 增至约 6.5KB；没有新增库。保留当前静态数据架构和离线 App Shell，不为约 33KB 文本增量重构或拆改 PWA。构建提示入口大于 500KB（未压缩），已如实记录。
- Portrait 走正常 HTTP 图片缓存，不加入 Service Worker 激进预缓存。冷离线时未缓存肖像可能出现占位；正文仍在 App Shell 中。
