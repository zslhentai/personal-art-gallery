### 核验时排除／修正的候选

- 芝加哥官方 IIIF 图片接口实测403，不绕过；能确认精确藏本且有独立开放许可的，采用 Commons 文件，其他暂缓。
- 一张哈尔斯肖像实际为斯德哥尔摩1643年藏本，与芝加哥1627年记录不符，排除该配对。
- 科尔《远望尼亚加拉瀑布》候选包含巨大画框且摄影为 CC BY-SA；毕沙罗《喝咖啡的年轻农妇》的带框摄影为 CC BY。前者暂缓，后者换为芝加哥来源的 CC0 全画图。
- 博纳尔《乡间餐室》属于明尼阿波利斯，纠正候选中的菲利普斯误配；其1931年《早餐》候选美国期限不够明确，《格纹衬衫》候选低清，均不采用。
- 西涅克《圣特罗佩港》候选没有可信馆藏归属，换为版本清楚的《费利克斯·费内翁肖像》。
- 修拉《阿涅尔浴者》搜索返回习作，洛特雷克《在红磨坊》混入阿尔比的另一幅构图，未拿它们冒充成画。
- 《干草车》候选指向转载站；没有完成足够可靠的开放数字来源确认，暂不加入。本站已有透纳《无畏号》，本轮不重复添加。
- 北斋《神奈川冲浪里》与广重《三岛的朝雾》采用 Met 官方具体印本；不把其他机构的扫描绑定芝加哥元数据。某鹤图候选短边不足1200px，排除。
- 卡拉瓦乔、拉斐尔、提香等只选择能核实的版本；莱昂纳多“circle of”与提香1808年复制件不归为大师本人原作。
- 没有追加 Hopper、Wyeth、Dalí 等权利状态仍需谨慎的现代作品，也没有下载受限制的 MoMA 原站图像。当前 Signac 的 MoMA 藏本使用独立明确 PD-Art 的 Commons 文件。

## 标签封面

保留 Tags 的布局、字体和间距。`src/data/tag-covers.json` 为可选手工覆盖：

```json
{ "tag": "水面", "coverArtworkId": "commons-52401688" }
```

覆盖图必须存在且属于该标签。无覆盖时，`selectTagCovers` 先分配候选稀少的标签，优先未被使用的作品，再比较标签是否为主要题材、画幅是否便于辨认、curationOrder 与稳定ID。不可避免复用时仍尽量避开相邻重复；明确的手工选择优先。缺失或不匹配的配置会退回自动选择。

当前34个标签拥有34幅不同封面；八个常用标签固定为：风景—麦田与柏树、光影—倒牛奶的女仆、明亮—向日葵、夜景—星月夜、水面—代尔夫特风景、室内—白门、孤独—苦艾酒、梦幻—吻。它们题材和构图不同，刷新、深浅色切换与JSON记录重排均不改变选择。自动选择在不使用手工配置时也能为目前34个标签分配不同作品。

新增8个长期题材／氛围标签：宗教、建筑、山岳、动物、抽象、日光、温暖、神秘。每件仍为少量标签；现有别名兼容保留，未把艺术流派重复混进氛围标签。

## 性能与验证

高清图留在机构或 Commons，只有 Viewer／保存按需访问。384张新增预览构成400／800／1200px三档，全构图、比例占位、srcset及原有lazy loading均保留。全部570张预览共约48.19MiB，仅属于部署资产，不会首页一次下载。没有新增依赖或虚拟化。

构建入口483.68KB（gzip130.38KB），数据随现有静态入口增加；PhotoSwipe仍独立按需加载。PWA仍只预缓存App Shell，高清图不进worker缓存，预览仅按既有有界策略缓存；自动构建产生新的版本hash，既有更新提示不变。

- lint、18项单元／数据测试、build通过；覆盖重复ID／slug／图像／Wikidata作品、来源与像素、权利冲突、预览预算、作者命名、策展序号、封面稳定性和错误覆盖。
- 桌面Chromium、390px Chromium/WebKit全套回归：68项通过，1项桌面不适用的手机检查跳过；包括全190张预览实际显示、Artists/Tags/Filter/Random/Favorites/Detail/Viewer/Save/Backup/PWA、主题、刷新、详情直达与返回。新增Cleveland／Met藏本的高清查看和保存分别实测；原有跨域／失败降级测试保留。
- 修正截图断言：像素存在还必须opacity为1，再截取前20件。长页在超过WebKit32767物理像素上限时分段截图，不跳过逐件检查。
- 375／390／430及1280px首屏采样CLS均为0；390px本地筛选端到端约44ms。首屏0高清请求，手机仅请求4–7张预览，桌面约21张（浏览器lazy预取距离不同）。本地LCP约0.4–0.6秒，是无节流开发机器数据，不当作真实弱网指标。
- 全馆滚动在Chromium／WebKit均到达底部、无横向溢出、无页面错误、0高清请求；DOM约2348节点。实测帧时间中位数约16–16.7ms、p95约16.7ms／28ms。最终顺序的复测数值以本节追加记录为准。
- 来源链接与已有高清图HEAD未出现404；50条来源页面403，官方API／Commons元数据仍可读取，不能据此宣称作品已删除。15张旧高清图首次限流429，低频复查全部200。新128张高清文件实际GET均成功。

当前190件无需分页或虚拟化；浏览器模拟不替代真机iOS手势、低内存设备及弱网测试。外部机构和Commons依然可能限流或改变路径，来源台账及刷新脚本用于后续复查。`refresh-previews.py` 增加Cleveland CC0校验，保留Met/Commons审查，不自动替换未授权来源。

最终190件顺序滚动复测：Chromium 中位帧 16.7ms、p95 16.8ms、1252帧；WebKit 中位帧 16.0ms、p95 27.0ms、1221帧。两者均滚动至底部，0控制台错误、0高清请求、无横向溢出。

### CI实网保存检查修正

第一次线上检查67项通过、1项Cleveland桌面保存检查在关闭Viewer时达到60秒总限时；部署门禁正确阻止发布。两个实网检查包含45秒高清等待与最多30秒下载降级，原全局60秒不足以覆盖两段等待，改为仅这两类检查90秒。保存事件后显式恢复原页面焦点，用既有ESC行为关闭，并继续断言Viewer消失与详情URL。Viewer／保存实现均未改动，本地三浏览器补测6项全部通过。失败trace归档请求返回403，因此只记录日志确认的超时位置，不断言完整根因。后续完整CI仍是发布门禁。
